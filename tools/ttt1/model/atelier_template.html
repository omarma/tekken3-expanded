Atelier Jin / Kazuya

Cinq modèles : Jin arcade, Jin PS1, Jin TTT1, Kazuya TTT1 et Kazuya converti au format PS1. Page locale : elle contient des données du jeu, ne pas la publier. Rendu texturé : Modèle texturé.

Chaque pastille est une ligne du modèle. La barre indique le nombre de sommets propres à la pièce, le chiffre à droite les sommets empruntés à d'autres pièces (soudure de la peau). Dans la colonne « Kazuya — converti PS1 », « ← n » donne la ligne TTT1 d'origine. Survolez une pièce pour allumer son équivalent dans les autres versions. Les lignes grisées sont vides.

Chaque couleur est une version. Positions locales à l'os (bloc de positions), sans animation ; pour l'arcade, dont ce format n'est pas décodé, ce sont les normales. Là où les points se superposent, c'est le même sommet. Glisser pour tourner, molette pour zoomer.

Taille totale de chaque modèle, répartie par région du corps. La cible PS1 est de 26 364 octets : c'est la taille que doit respecter Kazuya converti pour prendre la place de Jin.
